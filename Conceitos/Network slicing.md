# Network slicing

Múltiplas redes lógicas (*slices*) sobre a mesma infraestrutura física, cada uma com requisitos próprios (ex.: banda larga móvel, ultrabaixa latência, IoT massivo). Aumenta a complexidade de gerenciamento — um dos motores da automação via [[RIC]] no [[O-RAN]].
